## 🔬 Current focus

- **Diffusion LoRA** — Krea 2, Ideogram 4, FLUX, Qwen-Image and Z-Image across
  person / style / logo / product categories
- **Loss engineering** — driving down validator img2img L2 reconstruction loss with
  rank, timestep-sampling and LR-schedule ablations instead of guesswork
- **Adaptive HP** — dynamics-driven config selection from dataset fingerprints and
  per-family learning-rate priors, replacing static bucket lookups
- **Training orchestration** — one repo, branch per hotkey, Docker per-commit builds,
  and a memory layer that carries findings between runs automatically
